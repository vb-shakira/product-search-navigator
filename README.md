# Product Search Navigator

Create a simple web app for Hybrid Search with Metadata Filtering.

- Use LangChain and ChromaDB.

- Include sample product documents in the backend and index them into ChromaDB.

- Implement hybrid search using keyword + vector search.

- Add metadata filtering by Product Category.

- Display search results with document text, category, and relevance score.

- Add a Vector Store Visualization section showing the indexed document chunks, their metadata, and a 2D visualization of their embeddings.

- Keep the UI simple and professional.
